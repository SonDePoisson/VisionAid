VisionAId se prépare.

Une seule fois, au premier lancement. Gardez l'ordinateur allumé et connecté à Internet.

    Si la connexion coupe, la préparation reprend là où elle s'était arrêtée. Ensuite, tout reste sur cet ordinateur.

    En attente du téléphone…

    Connecter le téléphone.

    1. Mettez le téléphone sur le même Wi-Fi que cet ordinateur.
    2. Visez le code avec l'appareil photo du téléphone, puis touchez le lien qui apparaît.
    3. Le navigateur indique que la connexion n'est pas privée : touchez Afficher les détails (iPhone) ou Paramètres avancés (Android), puis continuez vers le site. La connexion reste chez vous, entre le téléphone et cet ordinateur.
    4. Touchez Démarrer sur le téléphone, puis autorisez la caméra et le micro.

    Sans appareil photo, tapez dans le navigateur du téléphone :

    Retour
    Devant Gauche Droite

    Tester le casque.

    Branchez le casque sur le téléphone et mettez-le. Le test joue un son à gauche, à droite, puis devant.

    Les trois sons venaient-ils du bon côté ?
    • Gauche et droite inversées : le casque est peut-être à l'envers (repères L et R).
    • Le même son des deux côtés : désactivez l'audio mono du téléphone (iPhone : Réglages › Accessibilité › Audio/Visuel ; Android : Paramètres › Accessibilité › Audio).
    • Aucun son : montez le volume du téléphone et vérifiez la connexion du casque.

      Aide.

      Utiliser VisionAId

      1. Fixer le téléphone sur le torse, écran vers soi.
      2. Mettre le casque et toucher Démarrer sur le téléphone.
      3. Appuyer sur Parler et dire « je cherche ma gourde ».
      4. Suivre le son. Dire « stop » pour arrêter.

      Un problème ?

      Le téléphone n'arrive pas à se connecter
      • Le téléphone et l'ordinateur doivent être sur le même Wi-Fi.
      • Si une adresse ne marche pas, essayez une autre adresse affichée sous le code QR.
      • Sous Windows, autorisez VisionAId quand le pare-feu le demande.
      • Reconnecter le téléphone
      Pas de son, ou le son vient du mauvais côté
      • Vérifiez le volume du téléphone et la connexion du casque.
      • Désactivez l'audio mono du téléphone (iPhone : Réglages › Accessibilité › Audio/Visuel ; Android : Paramètres › Accessibilité › Audio).
      • Vérifiez que le casque n'est pas à l'envers (repères L et R).
      • Rejouer le test du casque
      VisionAId ne comprend pas la demande
      • Parlez après le bip, dans un endroit calme.
      • Pour l'instant, VisionAId cherche la gourde et les clés : « je cherche ma gourde », « où sont mes clés ».
      L'objet n'est pas trouvé
      • Tournez lentement sur vous-même : la caméra doit voir l'objet.
      • Allumez la lumière : dans le noir, la caméra voit mal.
      • Vérifiez que rien ne cache la caméra du téléphone.

      Tout reste chez vous

      Le calcul se fait sur cet ordinateur. Les images de la caméra et la voix ne sont jamais envoyées sur Internet. Rien n'est enregistré, sauf si l'enregistrement est activé dans le mode avancé.
