# Journal des décisions

Format : date — contexte — choix — alternative écartée.

- **2026-11-21 — Données d'entrée** — Les fichiers fournis sont `assets/IMG_0270.MOV` (HEVC 1920×1080, rotation 90°, 16,2 s, 30 fps) et deux photos HEIC. Copie du flux vidéo sans ré-encodage vers `data/video/appart.mp4` (métadonnée de rotation conservée, pour exercer la gestion de rotation) et conversion des HEIC en `data/ref/gourde_{1,2}.jpg` via `sips`. — Alternative écartée : ré-encoder en H.264 en appliquant la rotation (perte de qualité et le test de rotation devenait trivial).
- **2026-11-21 — Version de Python** — Le dépôt initial impose Python 3.12 (`.python-version`, `requires-python>=3.12`). On garde 3.12 au lieu du 3.11 du plan : toutes les dépendances sont disponibles. — Alternative écartée : rétrograder vers 3.11 (aucun bénéfice).
- **2026-11-21 — open3d** — open3d 0.20 (wheel macOS arm64) dépend de `/opt/homebrew/opt/libusb` absent ; installer via Homebrew sort du périmètre réseau autorisé. 2ᵉ tentative : open3d 0.19 qui fonctionne. Contrainte `open3d<0.20`. numpy forcé en 2.x (pyarrow, requis par rerun, exige numpy ≥ 2).
- **2026-11-21 — Config en dataclasses** — Les dataclasses de config sont générées dynamiquement à partir du YAML (`dataclasses.make_dataclass`), accès par attribut `cfg.section.cle`. — Alternative écartée : écrire à la main ~20 dataclasses dupliquant le YAML (risque de désynchronisation).
- **2026-11-21 — HWM ZeroMQ** — 1000 messages envoyés en rafale avec HWM=1000 en émission et réception perdaient le dernier message. HWM par défaut relevé à 10 000 pour les flux légers (le mode conflate n'est pas concerné). — Alternative écartée : contrôle de flux applicatif (inutile à ces débits).
- **2026-11-21 — Enveloppe bus** — Message ZeroMQ mono-partie `sujet|t_envoi(float64)|msgpack` : ZMQ_CONFLATE ne supporte pas les messages multi-parties ; une socket par sujet en mode conflate. L'horodatage mural d'envoi permet de mesurer l'âge des entrées.
- **2026-11-21 — Tokenizer CLIP pour YOLOE** — Ultralytics veut installer le paquet `clip` depuis GitHub (refusé par la politique de l'environnement : hors pip/uv/HF). YOLOE n'en utilise que `clip.clip.tokenize` ; `perception/clip_shim.py` fournit un tokenizer équivalent via `transformers.CLIPTokenizer` (même BPE, contexte 77, ids identiques). L'encodeur texte MobileCLIP2 vient des assets Ultralytics. — Alternative écartée : repli direct sur YOLO COCO « bottle » (perte de l'open-vocabulary).
- **2026-11-21 — Token Hugging Face expiré** — Un token HF « hackathon » expiré est configuré sur la machine et fait échouer même les téléchargements publics. `visionaid/__init__.py` positionne `HF_HUB_DISABLE_IMPLICIT_TOKEN=1` (tous les modèles utilisés sont publics). **À faire par toi** : renouveler ou supprimer ce token (`hf auth logout`).
- **2026-11-21 — Détecteur** — YOLOE-26s-seg (`yoloe-26s-seg.pt`) disponible et retenu ; seuil de confiance bas (0,10) car la ReID filtre ensuite. Les fallbacks YOLOE-11 → YOLO-World → COCO sont codés mais non exercés. Prompt visuel YOLOE non activé (`use_visual_prompt: false`) : la spécificité vient de la ReID ; à essayer en phase 12.
- **2026-11-21 — Modèle couleur** — Sous l'éclairage chaud de l'appartement, l'inox de la gourde a H≈17-22 et S≈80-156 : un « gris » défini par S ≤ 50 ne le capte pas. Orange = H∈[5,30], S≥150, V≥100 ; gris/métal = S≤140, V≥50 (mesuré sur les photos de référence).
- **2026-11-21 — Score ReID multiplicatif** — Avec une moyenne arithmétique 0,6·embedding + 0,4·couleur, la gourde teintée en bleu passait le seuil (DINOv2 est peu sensible à la teinte). Score = moyenne géométrique pondérée `emb^0.6 · couleur^0.4` : une couleur absente annule le score. Le test de teinte décalée passe.
- **2026-11-21 — Négatifs de calibration** — La gourde apparaît dans la vidéo : les « négatifs » les mieux notés étaient la gourde elle-même. Règle d'exclusion : similarité DINOv2 ≥ 0,60, ou ≥ 0,45 avec score couleur ≥ 0,5. Effet de bord : 3 crops d'un sac orange (sim 0,46-0,48) sont exclus à tort. Seuil calibré (max F1) : 0,575 ; négatifs restants max 0,53.
- **2026-11-21 — Gating d'apparence du tracker** — Bug trouvé par le contrôle couleur : quand la gourde n'était pas détectée, sa piste confirmée sautait sur la boîte de céréales voisine. Une piste confirmée ne peut plus s'apparier à une détection de score < 0,6×seuil, et une détection n'est désignée « cible » que si son score ≥ 0,85×seuil.
- **2026-11-21 — Contrôle couleur vidéo** — Interprétation de « teinte dominante incompatible » : parmi les pixels saturés (S≥80), si > 25 % du masque est saturé et que la teinte dominante n'est pas dans [0,35]∪[170,180] (rouge/orange/brun), c'est incompatible. Un premier critère « aucun pixel orange » signalait à tort la gourde vue partiellement (haut seul, gros plan en main).
